================================================================================
 FRONTEND: Sidebar & Menu Structure
 Deskripsi : Pemetaan menu navigasi sidebar untuk setiap Role
================================================================================

 Aplikasi ini menganut konsep Multi-Tenant (SaaS). Oleh karena itu, kita memiliki 2 jenis Workspace/Sidebar utama: 
 1. SAAS WORKSPACE (Khusus Super Admin pengelola Wanterprise)
 2. COMPANY WORKSPACE (Untuk Perusahaan/Client yang menyewa layanan)

 ─────────────────────────────────────────────────────────────────────────────
 1. SAAS WORKSPACE SIDEBAR (Hanya muncul jika user adalah Super Admin)
 ─────────────────────────────────────────────────────────────────────────────
 📊 Dashboard
    ├─ Aksi: Menampilkan metrik global (Total Companies, Total Pendapatan, dll).
 
 🏢 Companies (Tenants)
    ├─ Aksi: Menampilkan daftar perusahaan pelanggan.
    ├─ Sub-aksi: Tambah Perusahaan, Suspend Perusahaan, Akses Login As (Menyamar sebagai admin perusahaan tersebut untuk bantuan support).

 👨‍💻 SaaS Users
    ├─ Aksi: Manajemen user internal Wanterprise (Super Admin lain).

 ⚙️ System Settings
    ├─ Aksi: Konfigurasi global (Maintenance mode, SMTP Email, dll).


 ─────────────────────────────────────────────────────────────────────────────
 2. COMPANY WORKSPACE SIDEBAR (Akses: Admin, Supervisor, Operator)
 ─────────────────────────────────────────────────────────────────────────────
 *Menu yang muncul akan disesuaikan dengan Spatie Permissions masing-masing role.

 📈 Dashboard (Admin, Supervisor)
    ├─ Aksi: Statistik harian (Pesan terkirim, sisa saldo, kualitas nomor WA).

 💬 Inbox (Semua Role)
    ├─ Aksi: Membuka antarmuka chat utama (Live Chat).
    ├─ Visibilitas: 
       > Operator: Hanya melihat chat kontak/nomor yang di-assign padanya.
       > Admin/Spv: Melihat seluruh chat dari semua nomor perusahaan.

 👥 Contacts (Semua Role)
    ├─ Sub-menu: 
       ├─ All Contacts (Aksi: CRUD Kontak)
       ├─ Contact Labels (Aksi: Manajemen segmentasi/grup kontak)

 🚀 Blast Campaigns (Admin, Supervisor)
    ├─ Aksi: Membuat, menjadwalkan, dan memantau pengiriman pesan massal.
    ├─ Sub-menu: 
       ├─ Campaigns List
       ├─ Templates (Jika ingin menyimpan template pesan)

 💳 Billing & Wallet (Admin)
    ├─ Aksi: Melihat sisa saldo prabayar, riwayat pemotongan saldo (transactions), dan tombol Top-Up.

 ⚙️ Settings (Admin)
    ├─ Sub-menu:
       ├─ WA Numbers (Aksi: Scan QR / Setup Token, Cek status webhook Meta)
       ├─ Team & Users (Aksi: Tambah staf, assign nomor WA / kontak ke operator)
       ├─ Roles & Permissions (Aksi: Mengatur batas hak akses custom)
       ├─ Company Profile (Aksi: Ubah nama, logo perusahaan)

 ─────────────────────────────────────────────────────────────────────────────
 LOGIC UI / UX DI VUE.JS
 ─────────────────────────────────────────────────────────────────────────────
 - Jika `user.company_id` bernilai `null` (Super Admin), maka secara default sidebar yang terbuka adalah SAAS WORKSPACE.
 - Super Admin dapat melihat menu dropdown "Switch to Company" untuk masuk ke mode COMPANY WORKSPACE sebagai observer.
 - Jika `user.company_id` terisi (user normal), maka menu SAAS WORKSPACE tidak akan pernah di-render ke frontend sama sekali.
 - Komponen Sidebar akan mengecek izin (contoh: `v-if="$page.props.auth.can['billing.view']"`) untuk merender menu Billing.
