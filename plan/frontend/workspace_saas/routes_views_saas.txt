================================================================================
 FRONTEND: SaaS Workspace Routes & Views (Vue.js + Inertia)
 Deskripsi : Pemetaan halaman SPA khusus untuk Super Admin (Pengelola SaaS)
================================================================================

 1. LAYOUT
 ─────────────────────────────────────────────────────────────────────────────
 - SaasLayout.vue : Mengandung <SidebarSaas /> dan Top Navbar khusus admin pusat.

 2. PETA ROUTE & VIEWS
 ─────────────────────────────────────────────────────────────────────────────
 Base Prefix: `/admin`

 [Dashboard]
 GET  /admin                   -> Saas/Dashboard.vue
      (Menampilkan statistik global: total tenant, MRR, server status)

 [Companies (Tenants) Management]
 GET  /admin/companies         -> Saas/Companies/Index.vue
 GET  /admin/companies/create  -> Saas/Companies/Create.vue
 GET  /admin/companies/{id}    -> Saas/Companies/Show.vue 
      (Halaman ini mencakup Tab untuk me-manage/kick user dari Workspace ini)

 [Platform Users (Global)]
 GET  /admin/platform-users    -> Saas/PlatformUsers/Index.vue
      (Menampilkan semua user lintas perusahaan untuk kebutuhan Suspend Global)

 [Internal Staff & Roles Management]
 GET  /admin/staff             -> Saas/Staff/Index.vue
 GET  /admin/staff/create      -> Saas/Staff/Create.vue
 GET  /admin/roles             -> Saas/Roles/Index.vue
 GET  /admin/roles/create      -> Saas/Roles/Create.vue

 [Global Settings]
 GET  /admin/settings          -> Saas/Settings/Index.vue
      (Konfigurasi SMTP, batas default upload, maintenance mode)

 3. STATE MANAGEMENT & LOGIC
 ─────────────────────────────────────────────────────────────────────────────
 - Di-render hanya jika user login memiliki role Super Admin.
 - Jika Super Admin melakukan aksi "Login As", mereka akan diarahkan ke Company Route & Layout.
