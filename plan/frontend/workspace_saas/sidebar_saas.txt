================================================================================
 FRONTEND: SaaS Workspace Sidebar
 Deskripsi : Pemetaan menu navigasi sidebar khusus untuk Operator SaaS (Super Admin)
================================================================================

 Sidebar ini hanya muncul jika user yang login memiliki Role `Super Admin` (difilter menggunakan Spatie Permissions, bukan sekadar melihat company_id).

 ─────────────────────────────────────────────────────────────────────────────
 MENU ITEMS
 ─────────────────────────────────────────────────────────────────────────────
 📊 Dashboard
    ├─ Aksi: Menampilkan metrik global (Total Companies, Total Pendapatan, dll).
 
 🏢 Companies (Tenants)
    ├─ Aksi: Menampilkan daftar perusahaan pelanggan.
    ├─ Sub-aksi: Tambah Perusahaan, Suspend Perusahaan, Akses Login As.
    ├─ Halaman Detail: Terdapat Tab "Workspace Users" untuk menghapus/kick user spesifik dari perusahaan ini saja (Suspend Parsial).

 🌍 Platform Users
    ├─ Aksi: Menampilkan seluruh user Wanterprise lintas perusahaan.
    ├─ Sub-aksi: Suspend Global Account (banned `is_active = false`), Reset Password.

 👨‍💻 Internal Staff & Roles
    ├─ Sub-menu:
       ├─ Staff Directory (Aksi: Manajemen staf internal pengelola SaaS)
       ├─ Roles & Permissions (Aksi: Mengatur custom roles untuk scope 'saas', misal Role 'Support Agent')

 ⚙️ System Settings
    ├─ Aksi: Konfigurasi global (Maintenance mode, SMTP Email, dll).

 ─────────────────────────────────────────────────────────────────────────────
 UX / UI BEHAVIOR
 ─────────────────────────────────────────────────────────────────────────────
 - Toggle Hide/Show: Sidebar HARUS bisa disembunyikan (full hide) dan dimunculkan (show) kembali untuk memperluas area kerja utama.
 - Pemicu (Trigger): Terdapat sebuah tombol/icon toggle (hamburger menu / sidebar-toggle) di area Top Navbar.
 - State Penyimpanan: Status sidebar (terbuka atau tertutup) disarankan disimpan di localStorage agar persisten antar sesi.
