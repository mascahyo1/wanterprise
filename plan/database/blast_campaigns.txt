================================================================================
 TABLE: blast_campaigns
 Deskripsi : Kampanye blast message — pengiriman pesan massal ke banyak kontak
================================================================================

 COLUMNS
 ─────────────────────────────────────────────────────────────────────────────
 id                  UUIDv7              PK
 company_id          UUIDv7              FK → companies.id
 wa_number_id        UUIDv7              FK → wa_numbers.id
 created_by          UUIDv7              FK → users.id
 name                string(255)         Nama kampanye
 wa_template_id      UUIDv7              FK → wa_templates.id (Wajib menggunakan template yang disetujui Meta)
 template_params     json null           Mapping data kontak (variable) ke komponen template (header, body, button)
 status              enum                draft | scheduled | running | done | failed
 scheduled_at        timestamp null      Waktu jadwal kirim (null = langsung)
 started_at          timestamp null      Waktu mulai dikirim
 completed_at        timestamp null      Waktu selesai
 total_recipients    int unsigned        Total penerima
 total_sent          int unsigned        Default: 0
 total_delivered     int unsigned        Default: 0
 total_read          int unsigned        Default: 0
 total_failed        int unsigned        Default: 0
 created_at          timestamp
 updated_at          timestamp

 INDEXES
 ─────────────────────────────────────────────────────────────────────────────
 • INDEX   company_id
 • INDEX   wa_number_id
 • INDEX   status
 • INDEX   scheduled_at

 RELATIONS
 ─────────────────────────────────────────────────────────────────────────────
 • belongsTo  companies             (blast_campaigns.company_id → companies.id)
 • belongsTo  wa_numbers            (blast_campaigns.wa_number_id → wa_numbers.id)
 • belongsTo  users                 (blast_campaigns.created_by → users.id)
 • belongsTo  wa_templates          (blast_campaigns.wa_template_id → wa_templates.id)
 • hasMany    blast_recipients      (blast_recipients.blast_campaign_id → blast_campaigns.id)
 • hasMany    messages              (messages.blast_campaign_id → blast_campaigns.id)

 NOTES
 ─────────────────────────────────────────────────────────────────────────────
 • PK menggunakan UUIDv7 — time-sortable, aman untuk distributed system
 • Pengiriman diproses via Laravel Queue (background job), bukan sinkron
 • total_sent / delivered / read / failed diupdate secara realtime via webhook
 • HARUS MENGGUNAKAN TEMPLATE: Mengikuti aturan ketat Meta Cloud API, pesan blast tidak bisa diketik manual (free-text). Wajib mengacu pada `wa_template_id` yang berstatus APPROVED.
 • Permission: blast.create, blast.send
================================================================================
