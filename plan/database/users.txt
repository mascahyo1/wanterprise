================================================================================
 TABLE: users
 Deskripsi : Khusus pengguna tenant/klien (Company Owner, Supervisor, Operator).
================================================================================

 1. COLUMNS
 ─────────────────────────────────────────────────────────────────────────────
 id                  UUIDv7              PK
 name                string(255)         Nama lengkap
 email               string(255)         Email login (unique)
 password            string(255)         Bcrypt hashed
 avatar              string(255) null    Path avatar/foto profil
 theme_preference    enum                light | dark | system (default: system)
 is_active           boolean             Default: true
 current_company_id  UUIDv7 null         FK → companies.id (Boleh NULL HANYA saat fitur "SaaS Mode" aktif)
 last_login_at       timestamp null      Waktu login terakhir
 created_at          timestamp
 updated_at          timestamp
 deleted_at          timestamp null      Soft delete

 2. INDEXES
 ─────────────────────────────────────────────────────────────────────────────
 • UNIQUE  email
 • INDEX   is_active
 • INDEX   current_company_id

 3. RELATIONS
 ─────────────────────────────────────────────────────────────────────────────
 • belongsToMany  companies              (via company_user.user_id → users.id)
 • belongsTo      current_company        (users.current_company_id → companies.id)
 • morphMany      (Spatie) roles
 • morphMany      (Spatie) permissions
 • hasMany        messages               (messages.sent_by → users.id)
 • belongsToMany  contacts              (via contact_assignments.user_id → users.id)
 • belongsToMany  wa_numbers            (via wa_number_assignments.user_id → users.id)

 4. NOTES
 ─────────────────────────────────────────────────────────────────────────────
 • PK menggunakan UUIDv7 — time-sortable, aman untuk distributed system
 • User bisa terikat pada banyak perusahaan (Many-to-Many via tabel `company_user`).
 • `current_company_id` mengatur konteks workspace (Tenant Mode). Kolom ini boleh `null` JIKA DAN HANYA JIKA user tersebut sedang mengaktifkan "SaaS Mode" (berjalan di level sistem).
 • Hak akses untuk memunculkan tombol "Switch to SaaS Mode" ditentukan dari eksistensi `user_id` mereka di tabel `saas_users` dengan status `is_active = true`.
 • Soft delete agar history pesan & aktivitas tetap terjaga
================================================================================
