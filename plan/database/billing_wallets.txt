================================================================================
 TABLE: billing_wallets
 Deskripsi : Saldo pra-bayar per perusahaan (model prepaid)
================================================================================

 COLUMNS
 ─────────────────────────────────────────────────────────────────────────────
 id                  UUIDv7              PK
 company_id          UUIDv7              FK → companies.id (unique — 1 wallet per company)
 balance             decimal(15,2)       Saldo saat ini (dalam satuan IDR / kredit)
 currency            string(3)           Default: IDR
 low_balance_threshold decimal(15,2)     Batas saldo untuk trigger alert (contoh: 50000)
 created_at          timestamp
 updated_at          timestamp

 INDEXES
 ─────────────────────────────────────────────────────────────────────────────
 • UNIQUE  company_id

 RELATIONS
 ─────────────────────────────────────────────────────────────────────────────
 • belongsTo  companies             (billing_wallets.company_id → companies.id)
 • hasMany    billing_transactions  (billing_transactions.wallet_id → billing_wallets.id)

 NOTES
 ─────────────────────────────────────────────────────────────────────────────
 • PK menggunakan UUIDv7 — time-sortable, aman untuk distributed system
 • Balance tidak boleh negatif — validasi di service layer
 • Alert otomatis jika balance < low_balance_threshold
 • Semua perubahan balance WAJIB melalui billing_transactions (audit trail)
================================================================================
