================================================================================
 TABLE: contact_assignments
 Deskripsi : Pivot — kontak yang di-assign ke pengguna tertentu (agen)
================================================================================

 COLUMNS (Pivot Table)
 ─────────────────────────────────────────────────────────────────────────────
 id                  UUIDv7              PK
 contact_id          UUIDv7              FK → contacts.id
 user_id             UUIDv7              FK → users.id
 assigned_by         UUIDv7              FK → users.id (siapa yang assign)
 assigned_at         timestamp           Waktu di-assign
 notes               text null           Catatan assignment

 INDEXES
 ─────────────────────────────────────────────────────────────────────────────
 • UNIQUE  contact_id + user_id
 • INDEX   user_id
 • INDEX   contact_id

 RELATIONS
 ─────────────────────────────────────────────────────────────────────────────
 • belongsTo  contacts              (contact_assignments.contact_id → contacts.id)
 • belongsTo  users [user_id]       (contact_assignments.user_id → users.id)
 • belongsTo  users [assigned_by]   (contact_assignments.assigned_by → users.id)

 NOTES
 ─────────────────────────────────────────────────────────────────────────────
 • PK menggunakan UUIDv7 — time-sortable, aman untuk distributed system
 • Digunakan untuk fitur permission contact.list_assigned & message.send_assigned
 • User dengan permission contact.list_assigned hanya bisa lihat kontak
   yang ada di tabel ini dengan user_id = user mereka
 • Satu kontak bisa di-assign ke lebih dari satu agen
================================================================================


================================================================================
 TABLE: wa_number_assignments (PIC Nomor WA)
 Deskripsi : Akses dan peran (PIC) user/employee terhadap nomor WA tertentu
================================================================================

 COLUMNS (Pivot Table)
 ─────────────────────────────────────────────────────────────────────────────
 id                  UUIDv7              PK
 wa_number_id        UUIDv7              FK → wa_numbers.id
 user_id             UUIDv7              FK → users.id (employee_id)
 description         text null           Catatan atau deskripsi tugas PIC
 can_send            boolean             True jika PIC boleh mengirim/membalas pesan
 status              boolean             True jika aktif, False jika akses ditangguhkan
 can_assign          boolean             True jika PIC ini boleh assign chat/nomor ke staf lain
 can_read_all        boolean             True jika bisa baca semua chat di nomor ini, False jika hanya chat yang di-assign padanya
 assigned_by         UUIDv7 null         FK → users.id (siapa yang assign)
 created_at          timestamp
 updated_at          timestamp

 INDEXES
 ─────────────────────────────────────────────────────────────────────────────
 • UNIQUE  wa_number_id + user_id
 • INDEX   user_id
 • INDEX   status

 RELATIONS
 ─────────────────────────────────────────────────────────────────────────────
 • belongsTo  wa_numbers            (wa_number_assignments.wa_number_id → wa_numbers.id)
 • belongsTo  users [user_id]       (wa_number_assignments.user_id → users.id)
 • belongsTo  users [assigned_by]   (wa_number_assignments.assigned_by → users.id)

 NOTES
 ─────────────────────────────────────────────────────────────────────────────
 • PK menggunakan UUIDv7 — time-sortable, aman untuk distributed system
 • Berfungsi sebagai kontrol akses tingkat nomor WhatsApp (Inbox).
 • can_read_all: Jika false, user hanya bisa baca message/contact yang diassign padanya (via contact_assignments). Jika true, dia punya akses penuh ke semua chat di nomor ini.
================================================================================
